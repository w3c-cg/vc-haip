# Outreach images

Images to announce the High Assurance Profile for W3C VCDM 2.0 Community Group (vc-haip), for social media, slides and print.

| File | Use |
|---|---|
| `vc-haip-announcement.svg` / `.png` | Social media posts (1200 × 627) |
| `vc-haip-announcement-qr.svg` / `.png` | Slides, print and events; the QR code links to https://www.w3.org/community/vc-haip/ |
| `source/` | Editable HTML sources, the W3C logo and the QR code |

- **SVG** files are self-contained: the W3C logo, the QR code and the Noto Sans font (subset, SIL Open Font License) are embedded. They display the same in any web browser. Some graphics editors ignore embedded web fonts; use the PNG there.
- **PNG** files are exported from the SVGs at 2× (2400 × 1254).

## Alt text

> W3C logo. New W3C Community Group: High Assurance Profile for W3C VCDM 2.0 (vc-haip). Verifiable credentials for decisions with legal or economic effect, including evidence that AI agents and robots act on. Open to all, free to join, W3C membership not required. w3.org/community/vc-haip

For the QR version, add: "QR code links to the group page."

## W3C logo

The images use the official W3C logo under the [W3C logo and icon use policies](https://www.w3.org/policies/logos/) and the W3C Brand Standards (October 2025):

- The logo is unaltered, complete (symbol and wordmark), at least 60 px in size and has at least 60 px of clear space.
- No W3C imagery (spirals, circles) or W3C icons are used.
- Colours: W3C Blue `#005a9c`, W3C Dark Blue `#002a56`, Dark Gray `#545454`. Font: Noto Sans.
- The images do not imply W3C endorsement. They state: "Community Group reports are not W3C Standards."
- When used on the web, the logo must link to https://www.w3.org/.

The W3C logo is a trademark of W3C. It is not covered by this repository's licence.
